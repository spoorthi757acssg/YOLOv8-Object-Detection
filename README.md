**YOLOv8-Object-Detection: Object Detection using YOLOv8 Nano trained on the COCO8 dataset with Ultralytics and PyTorch.**

**YOLOv8 Object Detection**

This project uses the YOLOv8 Nano model to detect objects in images. The model is trained on the COCO8 dataset using the Ultralytics YOLO framework and can identify multiple objects with their class names and confidence scores.

**About the Project**

Object detection is a computer vision task that identifies the location and category of objects in an image. In this project, the YOLOv8 Nano model is trained on the COCO8 dataset and tested on validation images to detect different objects.

**Features**

Object detection using YOLOv8 Nano
Training on the COCO8 dataset
Model evaluation using standard metrics
Detection on new images
Displays bounding boxes and class labels

**Dataset**

Dataset: COCO8
Framework: Ultralytics YOLO
Task: Object Detection

**Technologies Used**

Python
Ultralytics YOLOv8
PyTorch
OpenCV
Jupyter Notebook

**Project Workflow**

1. Install the required libraries.
2. Load the YOLOv8 Nano model.
3. Train the model on the COCO8 dataset.
4. Evaluate the trained model.
5. Perform object detection on validation images.
6. Display the detected objects.

**Installation**

Clone the repository:

```bash
git clone https://github.com/your-username/yolov8-object-detection.git
cd yolov8-object-detection
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Open the notebook:

```bash
jupyter notebook
```

Run:

```
YOLO.OBJECT.DETECTION.ipynb
```
